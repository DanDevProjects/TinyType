# TinyType

TinyType is a lightweight, no-bloat text editor for Windows and macOS.

## 📥 Installation

### Windows

1. Go to the Releases page. (on the sidebar)
2. Download the latest Windows setup.exe release.
3. Use the installer to install.
4. Once finished, go the the start menu and launch the app.
> **Windows SmartScreen:** Windows may display a warning because TinyType may not have a widely recognized code-signing certificate. If you downloaded TinyType from this official GitHub repository, verify that you downloaded the correct release before choosing to run it.

### macOS

1. Go to the Releases page.
2. Download the latest macOS .dmg release.
3. Open the .dmg and move the application to the Applications folder.
4. Move TinyType to your **Applications** folder.
5. Open TinyType.

> **macOS security warning:** macOS may prevent TinyType from opening if the application is not notarized. If you trust the download and macOS blocks it, you can allow it through **System Settings → Privacy & Security**.

## 💻 Requirements

### Windows 
min requirements:
* Windows 8.1 or later (recommended Windows 10 or later)
* 1GB of RAM (2 GB of RAM recommended)
* 10 MB of storage (1 GB recommended for daily use)
* 1 Ghz or more (1.5 GHZ recommended)
* No additional runtime should be required unless specified by the release

### macOS
min requirements:

## 🚀 Usage

TinyType is designed to be straightforward:

1. Open TinyType.
2. Create or open a document.
3. Write or edit your content.
4. Save the document using the desired format.

TinyType supports:

* Plain text (`.txt`)
* Rich Text Format (`.rtf`)
* Microsoft Word documents (`.docx`)
* Images
* Fonts installed on your system

## 📂 File Formats

| Format  | Open |            Save            |
| ------- | :--: | :------------------------: |
| `.txt`  |   ✅  |              ✅             |
| `.rtf`  |   ✅  |              ✅             |
| `.docx` |   ✅  |              ✅             |
| Images  |   ✅  | Depends on document format |

File-format behavior may vary between versions. If a format is important to you, test it before relying on TinyType for critical documents.

## ⚠️ Notices

### Early Release

TinyType is still an early-stage project. Although the application is intended for everyday use, bugs and unexpected behavior may occur.

**Back up important documents before editing or converting them with TinyType.**

### `.docx` Compatibility

TinyType's `.docx` support may not provide complete compatibility with every feature supported by Microsoft Word or other full-featured word processors.

Complex documents containing advanced formatting, embedded objects, macros, unusual fonts, or other unsupported features may not appear exactly as they do in Microsoft Word.

### Fonts

TinyType can use fonts installed on your operating system.

If a document uses a font that is not installed on your computer, the document may look different from the original.

### Images

Image support may depend on the document format and the way the image is embedded.

If an image is important, verify the saved document after saving.

## 🐛 Reporting Bugs

Found a bug?

Before opening an issue:

1. Make sure you are using the latest version.
2. Check the existing [Issues](../../issues).
3. Try reproducing the problem with a new or simple document.
4. Include your operating system and TinyType version.

When reporting a bug, please include:

* Operating system and version
* TinyType version
* Steps to reproduce the issue
* What you expected to happen
* What actually happened
* Screenshots or example files when appropriate

Please **do not upload private or sensitive documents** when reporting an issue.

## ❓ Frequently Asked Questions

### Is TinyType free?

Yes. TinyType is open source and distributed under the project's license.

### Does TinyType require an internet connection?

No internet connection should be required for normal use after TinyType has been installed.

### Does TinyType replace Microsoft Word?

No. TinyType is intended to be a lightweight editor, not a full replacement for Microsoft Word or other full-featured word processors.

### Why is TinyType so small?

TinyType is intentionally designed to have a very small footprint and avoid unnecessary dependencies and features.
