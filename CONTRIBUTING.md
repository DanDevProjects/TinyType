# Contributing Guidelines

Thank you for your interest in contributing to this project! We welcome all contributions, including bug reports, feature suggestions, and code changes.

## 🐛 Reporting Bugs
Before opening a new issue, please check the existing issues to ensure it hasn't been reported yet. 

When reporting a bug, please include:
* A clear description of the problem.
* Steps to reproduce the behavior.
* What you expected to happen vs what actually happened.

## 💡 Suggesting Enhancements
If you have an idea to improve the project, feel free to open an issue. Explain the goal of your suggested feature and how it should work.

## 🚀 Submitting Code (Pull Requests)
We happily accept pull requests! To contribute code:
1. Fork this repository.
2. Create a new branch for your specific change.
3. Make your code modifications.
4. Commit and push your changes to your fork.
5. Submit a pull request back to this main repository.

## 📜 General Rules
* Be respectful and welcoming to other community members.
* Ensure your code is clean, readable, and does not break existing functionality.
